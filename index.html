06

購物與退稅

購物集中在 D4：上午來客夢、下午豐崎 On 鞋、晚上國際通。退稅制度 11/1 剛改，先看清楚再決定要不要辦。

退稅新制：11/1 起改成「先付含稅、出境退款」

店內付含稅價，出境時在保安檢查前的海關確認商品，而且要在託運行李之前完成，確認後才退款。退款用的信用卡要先登記，建議出發前在 Visit Japan Web 登錄。新制同時取消消耗品的密封包裝與 50 萬圓上限。

但這班機太早了。11/15 08:15 起飛、06:40 才到機場，加上早班機人潮，很可能來不及。金額不大就別辦；真要辦，出門時間提前到 06:00。

D4 採買路線

  • 來客夢：10:50–13:10，3F ABC-MART GRAND STAGE 先看 On。

  • 壺屋やちむん通：陶器，請店家包好隨身帶。

幾個容易忘的細節

  • 店家優惠券和退稅是兩回事。唐吉訶德、BicCamera、Alpen 的觀光客折價券當場折抵，不受新制影響。券要存原圖給店員掃，截圖無效。
  • On 鞋最後備案：從牧志搭單軌 2 站到おもろまち。跑步專門店 Run Ride POINT（080-9854-7568），或 San-A 那霸 Main Place 2F 的 BUNRINDO SPORTS（098-951-3356，營業到 22:00）。有沒有 On 要先打電話問。

08

現場提醒

天氣、開車、禮儀，和萬一需要的電話。

11 月中的沖繩

  • 白天約 20–25°C，短袖就好；晚上和冷氣房要薄外套。
  • 飯店和租車的冷氣都開很強，邊戶岬、岬角一帶風也大。
  • 日落約 17:40。三天都在天黑前收車，晚上走路或在住宿處吃。
  • 自然景點多半沒有販賣部，車上放礦泉水和小點心。

開車

  • 導航用電話號碼或 MapCode 輸入最準，地址常找不到。下方速查表的電話可直接用。
  • 高速：那霸 IC → 許田 IC（D2）、許田 IC → 沖繩北 IC（D4）。D4 來客夢到豐崎照 Google Maps 即時路線。
  • 日本酒駕零容忍。D2 自煮、D3 燒肉走路去，晚上都不用開車，兩個人都可以喝。
  • 還車前加滿油並留收據。
